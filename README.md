# 泰拉瑞亚补丁整合包

面向 **Windows 原版 Terraria 1.4.5.8 单人游戏**的补丁安装器。内含 52 个插件，安装时选择“完整玩法”或“轻量便利”。

## 下载与安装

**[下载安装器（约 137 MiB）](https://github.com/823608044-droid/terraria-patch-bundle/releases/download/v2026.11.09.1/TerrariaPatchBundle-2026.11.09.1-Windows.exe)** · [发行说明和其他附件](https://github.com/823608044-droid/terraria-patch-bundle/releases/tag/v2026.11.09.1)

1. 先确认游戏能通过 Steam 正常启动，然后保存退出游戏。
2. 双击安装器，确认游戏目录，选择预设并安装。
3. 使用游戏目录中的 `TerrariaBundleStart.exe` 启动。进入游戏后按 **F6** 调整功能。

需要游戏正常运行所需的 .NET Framework 4.8 和 XNA Framework 4.0；安装器不需要开发工具。

## 两个预设

| 预设 | 默认加载 | 内容 |
| --- | ---: | --- |
| 完整玩法 | 49 项 | 便利、仓储、建造、查询、自制装备、精英遭遇及敌人属性强化 |
| 轻量便利 | 32 项 | 仓储、建造、查询和日常辅助，默认停用新增战斗装备及敌人强化 |

部分参与加载的插件，其具体功能仍默认关闭。原生自动钓鱼、特殊种子选项和 120 帧渲染可在安装时单独选择。地图传送、全图揭示默认关闭。

安装器提供版本与文件校验、已有补丁备份、预设切换和逐层恢复。其他旧插件保留在备份目录，避免与新包混合加载。角色和世界存档不由安装器覆盖。

这是**公开测试版**，仅支持上述单人环境。尚未完成第二台全新电脑、全部 Boss 完整战斗、所有蓝图和长期游玩覆盖。安装器逻辑通过 19 项检查，包内组合已做共同初始化、物品注册、装备与战斗组合及卸载检查；这些不能替代完整实战验收。

包内不含游戏本体、Steam DLL、个人存档或地图记录。创意工坊材质和音效请从发行附件中的订阅清单访问原作者页面。

因再分发许可待确认，本公开包不含 Ty 悠悠球移植、星轨套件、Boss 重制移植、True Bestiary、自动火把及自动重铸。
